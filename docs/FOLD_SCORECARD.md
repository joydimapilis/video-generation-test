# Fold — From scattered to started

A completely new 31-second launch film for a fictional AI creative-brief builder. Original script, UI, motion, local narration and score; no earlier generated footage and no interviews. Generation API cost: **$0 under a $10 cap**.

This is a composition review, not a new video-model benchmark. Existing routing evidence supports HyperFrames for exact interfaces and text. No cinematic plate would add necessary information to this paper-to-product story, so no paid model tests were run.

## Improvement loop

1. Planned shared window geometry at 9s and shared brief geometry at 21s before authoring scenes.
2. Initial snapshots exposed the opening headline crossing its small label. Reduced the entry travel so both remain clear.
3. Removed stretched text during the brief-to-board unfold: text retires before the paper changes proportions.
4. Encoded review and layout checks caught the two ending lines entering toward each other. Reversed the second line's entrance and bounded its board wrapper.
5. A final encoded transition review exposed an overly transparent paper morph. Kept the paper opaque while it expands, preserving the object throughout the reveal.
6. Re-rendered and rechecked the finished MP4. The final frame contains the completed board and CTA.
