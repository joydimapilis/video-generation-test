## New lessons

1. A correct source eye line can still drift during I2V. Review moving eyes relative to the physical screen, not facial attractiveness or only the first frame.
2. Specify downward pupil direction and chin angle as well as the named target. Breathing-only motion improved this particular retry; it is not a universal guarantee.
3. Before/after UI is stronger when source items remain the same objects during reflow. Keep order names, counts and special notes traceable across the transformation.
4. Let the final task state travel into the human payoff shot, then echo the opening quantity at the ending.
5. Source Serif 4's generous font metrics need explicit line metrics to avoid misleading overlap bounds at compact editorial leading. Final check must run layout, motion and contrast, not only lint.
