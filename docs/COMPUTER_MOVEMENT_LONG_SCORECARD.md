# Longer computer interaction studies

Three independently generated source images reused for six new I2V requests. No real reference footage, real extracted frame, pose or motion-control input was sent. Exact inputs, original image prompts, new motion prompts and upload hash checks: [audit](../review_notes/computer-movement-long-generation-audit.md).

Review used chronological full-scene/face frames at 2fps and hand crops at 8fps over all six full takes, plus critical native-resolution frames and encoded-output inspection. This is sampled visual inspection, not continuous playback or an objective realism measurement. Actual cursor/text response is hidden; no claim of verified computer state. Numerical dimensions remain null.

Rejected full takes: desktop Kling v1 (splay, off-keyboard reach); laptop Kling v1 (curl/hover and withdrawal); laptop Wan v2 (hand crossing); laptop Wan v3 beyond selected interval (hover). Preserved in the original loop output directories. The selected full original laptop is also supplied beside its nine-second delivery.
