# Kite Tomorrow — second UI pass

Editable full 38-second master with an independently revised UI workflow.
The original person shot, audio, story, page copy and scene timing are retained.
This project does not claim a new character-generation result.

`npm run check` validates the composition. `npm run render -- --quality delivery
--fps 30 --output <absolute-output.mp4>` renders it with pinned HyperFrames 0.8.46.
Source media remains local and excluded from Git.

The isolated UI study, comparison and human workflow review live in
`../kite-tomorrow-revised/studies/`. See `SCENE_ROUTING.md` there for current
model selection, observed failures, proposed human test, prices and budget limit.
Official UI reference: https://kite.ai/ (public demonstration, not a live account).
The UI adapts that reference with local Lato fonts, the official app icon,
channel tabs, message metadata, composer and documented Preview/Review actions.

Output folder: `../../artifacts/final_outcome/kite-tomorrow-ui-pass2/`.
No new paid generation; all earlier costs belong to the same Kite Tomorrow ledger.
