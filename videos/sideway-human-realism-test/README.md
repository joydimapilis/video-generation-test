# Sideway human-realism test

Open `../../artifacts/final_outcome/sideway-human-realism-test/review.html` for the delivered comparison and complete native-speed takes.

The editable HyperFrames project is `comparison/`. From that directory, use `npx hyperframes preview` or render with `npx hyperframes render --quality delivery --fps 24 --workers 2 --output <output.mp4>`. The project pins HyperFrames 0.8.49.

`build_comparison.py` rebuilds the comparison source and copies recovered assets. `comparison/selection.json` records exact comparison ranges. Generation configurations live in `../../configs/sideway_sample02_realism_test.json` and `../../configs/sideway_sample02_reading_correction.json`; do not rerun paid generation to rebuild the local comparison.

Three new takes were reviewed; none was selected to replace original Sideway footage. See `../../review_notes/sideway/sample02-test-results.md` for outcomes, reference use, provenance and cumulative cost. The original full film remains unchanged.
