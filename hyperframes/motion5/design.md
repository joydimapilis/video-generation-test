# Motion-5 Reference Design

Concept: a playful character becomes a useful teammate, then a team whose finished work is immediately readable.

Canvas: 1920x1080, 30fps, 32.533333 seconds. Background #fafafa; foreground #111111; secondary #666666; borders #e5e5e5. Character accents cyan #229de5, yellow #edb600, mint #12d6a0. No added decoration. Near-white negative space is source-derived.

Font: locally bundled Arial, regular and bold, matching the source's neutral sans. Headings 58-68px; primary UI 28-34px; secondary UI at least 22px at presentation scale. Zero letter spacing.

Focal elements: source mascot, then chat request, then connected tools, then expanding specialist workspace, then summary checklist. Brand lockups center on the canvas. Interface windows have thin gray borders, 8px radii and subtle shadows. UI is recreated HTML with deterministic timeline reveals.

Motion: spring-pop-entrance for the playful opening, stagger-cascade registry recipe for tools and task rows, continuous scale/translation for workspace expansion and return. Reference soundtrack reused at its original timing and volume.
